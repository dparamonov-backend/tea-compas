# Чайный компас — изумрудная версия

Полностью обновлённый адаптивный сайт на Flask.

## Что изменено
- Новый изумрудный дизайн с золотистыми деталями.
- Новое меню из 9 страниц в просмотрщике: стрелки, клавиши ←/→, точки страниц и свайпы на телефоне.
- Сохранена форма бронирования и SQLite-база `bookings.db` из переданного проекта.
- Уведомление о заявке в Telegram: настройка через `.env`.

## Запуск на Windows
1. Python 3.11+
2. `py -m venv .venv`
3. `.venv\Scripts\Activate.ps1`
4. `pip install -r requirements.txt`
5. Скопируйте `.env.example` в `.env` и заполните настройки Telegram и секрет Flask.
6. `python app.py`
7. Откройте `http://127.0.0.1:5000`.

Не публикуйте `.env` и не добавляйте его в Git. Если у вас уже есть рабочий `.env`, перенесите его в эту папку вручную.
