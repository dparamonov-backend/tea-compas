# Чайный компас

Первый вариант сайта на Flask в стиле предоставленного меню.

## Что есть
- Главная страница с меню церемоний.
- Сохранение оригинального изображения меню.
- Адаптивный тёмный дизайн с золотистыми деталями.
- Форма записи: заявки сохраняются в SQLite (`bookings.db`).
- Разделы о чае, пуэре и дополнительных позициях на основе предоставленных материалов.

## Запуск на Windows

1. Установите Python 3.11 или новее.
2. Распакуйте архив и откройте папку проекта в терминале.
3. Создайте виртуальное окружение:

   ```powershell
   py -m venv .venv
   .venv\Scripts\Activate.ps1
   ```

4. Установите зависимости:

   ```powershell
   pip install -r requirements.txt
   ```

5. Запустите:

   ```powershell
   python app.py
   ```

6. Откройте адрес, который покажет Flask (обычно http://127.0.0.1:5000).

## Важно перед публикацией
- В `app.py` замените `app.secret_key` на случайный секрет из переменной окружения.
- Включите HTTPS на хостинге.
- Добавьте защищённый способ просматривать заявки: сейчас они записываются в SQLite, но административная страница не создана.
- Проверьте актуальность цен, ассортимента и расписания с владельцем чайной.
- Форма создаёт заявку, но не подтверждает бронь автоматически.
- SQLite подходит для локальной разработки; для некоторых облачных хостингов с временной файловой системой потребуется внешняя база данных или постоянный диск.
