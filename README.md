# Чайный компас — версия «лак и золото»

Flask-сайт чайной: вишнёво-чернильная палитра под меню блюд, золото, акценты сакуры и красного фонаря.

## Что нового
- Новая палитра и дизайн: компас в первом экране, лепестки сакуры, светлые «бумажные» блоки.
- Кнопка «Написать в Telegram» (https://t.me/tea_compas): в шапке, в первом экране, в блоке брони, в окнах церемоний и меню, плавающая на телефоне.
- 5 новых церемоний с окном подробностей. Данные и цены — в `app.py` (`NEW_CEREMONIES`), поправьте под себя.
- Меню блюд: страница 10 в просмотрщике и отдельный раздел со списком.
- Форма заявки сохранена, список церемоний в ней обновлён.

## Запуск на Windows
1. `py -m venv .venv`, `.venv\Scripts\Activate.ps1`, `pip install -r requirements.txt`
2. Скопируйте `.env.example` в `.env` и заполните настройки Telegram.
3. `python app.py`, откройте http://127.0.0.1:5000
